# Source acknowledgment and authorship boundaries

**Project presentation:** Margaret Kamau.

The project contains two different kinds of material:

1. **Scientific Computing Lab browser interface:** A browser-based JavaScript demonstration deployed at https://scientific-computing-shadownet.vercel.app/. It offers eight interactive numerical experiments and visualizations.
2. **Reference Python coursework files:** The `original-python/` directory preserves files from the publicly accessible repository https://github.com/omondijurgen58-cloud/SCIENTIFIC-FOR-COMPUTING2, with its original directory layout and existing incomplete placeholders. The source was inspected in November 2026.
